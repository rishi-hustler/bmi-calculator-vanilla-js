# BMI Calculator (Vanilla JavaScript)

An advanced BMI (Body Mass Index) calculator built using pure HTML, CSS, and JavaScript.

## Features
- Metric and Imperial unit support
- BMI calculation with WHO classification
- Input validation
- Persistent history using localStorage
- Clear history option
- Clean UI and modular code

## BMI Categories
- Underweight: < 18.5
- Normal weight: 18.5 – 24.9
- Overweight: 25 – 29.9
- Obese: ≥ 30

## Project Structure

bmi-calculator/
├── index.html
├── style.css
├── script.js
└── README.md

## How to Run

1. Download or clone the project
2. Open `index.html` in your browser
3. Enter height and weight
4. Select unit system and calculate BMI

## Persistence

BMI history is saved in the browser using:
localStorage key: bmiHistory
